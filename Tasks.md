Tasks

1.) Create optional definitions that chooses actors on the map that would like to roll all of their dice themselves. If actors are in this list, the model should pause, give a pop-up explaining what they are rolling (i.e. Dex save, to hit, etc...). 
2.) Wall creation. I would like for there to be an option for the user to create walls. This should work by having an option in the GUI to select hexes on the map that are walls that actors cannot pass through. The walls should be highlighted on the map and the engine should consider these walls as direct blocks that the actors cannot pass through. When deciding when and where to move, the engine should consider rerouting around these paths.
3.) GUI encounter window positions editable. I would like to be able to allow the user to move around grouped sections on the GUI. Some that come to mind are the initiative order window, the action selections, output text window, the map itself. Look through to see what else could potentially be added to this as well. The groups should be able to both be moved around inside the window, resized, and minimized.
4.) Some spells persist on the map and create obstacles that can do various things to actors that go through them (i.e. do damage, slow enemies, etc..). Can you work through the best way to both allow the users to use these spells in the GUI and implement was to show the colors. Also work in the engine itself. Find the best way to have these persist and in the decision logic, have actors account for the obstacle and calculate if its best to go through or around these objects. This should also consider that these spells do not last forever. They have a given time limit and can be ended early if the caster either takes damage and fails a concentration saving throw or they cast another concentration spell.
5.) Allow for monster classes to also have their choices decided by the user like players currently are. This should be saved in a list like manual roller and should allow for both players and monsters to be optional controlled by the user or the engine.
